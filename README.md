# gh600-lab

Public lab repository for hands-on practice toward **GitHub Certified: Agentic AI Developer (GH-600)**.

It holds a small study app (Spring Boot backend + React frontend) and the GitHub governance labs built around it: CI, rulesets, CODEOWNERS, plan checks and agent workflows.

- App docs: [docs/README.md](docs/README.md)
- Run locally: `.\start.ps1` from the repository root

Practice-exam questions are not included in this repository.
